# TP-Link TL-WR703N — installation research

## Historical reference

LibraryBox 2.1 documents a simple firmware installation for WR703N v1 through the TP-Link web administration interface: connect by Ethernet, browse to 192.168.1.1, navigate to firmware upgrade and upload the hardware-specific image.

Sources:
- https://jasongriffey.net/librarybox/buildingv2.1.php
- https://openwrt.org/toh/tp-link/tl-wr703n

**This is not yet a MikroWrt installation procedure.** Hardware/firmware revisions differ: OpenWrt's device page notes v1.7 stock firmware variants that reject web flashing and may require TFTP. Validate device ID and exact flash format before attempting any upgrade. Never flash a LibraryBox/PirateBox image merely to install MikroWrt.

## Required before a release

- [ ] Identify hardware revision via board and stock firmware.
- [ ] Confirm actual flash/RAM and partition map.
- [ ] Verify bootloader expectations, firmware header and checksums.
- [ ] Build device-specific factory image and sysupgrade image.
- [ ] Capture serial logs and test recovery path.
- [ ] Verify boot, Wi-Fi AP, DHCP and Ethernet on physical board.
